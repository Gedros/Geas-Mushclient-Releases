First public beta of the Geas MUSHclient package.

**Download:** Geas-Mushclient.zip below. New here? Follow the [quick start guide](https://github.com/Gedros/Geas-Mushclient-Releases/blob/main/QUICKSTART.md).

What is in it:
- A map that learns as you walk: click to walk, roads, doors, marks, notes, search, six map styles.
- Windows: vitals, chat (every channel in one window), inventory, stats and skills, armour, weapons and weapon sets, combat (foes, team, kills), specials with cooldowns.
- Docked, tabbed layouts and preset layouts; 21 colour schemes and 6 border styles; icon bars you make in game; line colours.
- A setup guide (`geas setup`, offered after you first log in): the basics in 16 short steps, with a text-only mode for screen readers.
- One Settings window for everything (`geas settings`).
- `geas report`: report a problem in a few clicks.

This is a beta: please report anything odd with `geas report`.
