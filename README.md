# Geas MUSHclient package

A complete MUSHclient set-up for [Geas](http://play.geas.com): a map that
learns as you walk, vitals, chat, inventory, weapons, combat, character
and specials windows, themes and colour schemes, icon bars and docked,
tabbed layouts.

## Download

**[Download the latest version](https://github.com/Gedros/Geas-Mushclient-Releases/releases/latest/download/Geas-Mushclient.zip)**

Every version and what changed: [Releases](https://github.com/Gedros/Geas-Mushclient-Releases/releases).

You need [MUSHclient](https://www.gammon.com.au/downloads/dlmushclient.htm)
5.06 on Windows.

## Install

The quick start guide comes with the first release (it is in the zip
too).

## Something wrong?

In MUSHclient, type **`geas report`** and say what happened. It writes a
report file and shows a link, **[Report it on GitHub]**, that opens a
report here with your words filled in. Drag the file in and press
**Create**.

The report never holds your login, your password or the words of your
conversations.

Or [report a problem](https://github.com/Gedros/Geas-Mushclient-Releases/issues/new/choose)
yourself (a free GitHub account is needed).
